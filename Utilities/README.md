# Utilities

Pure Swift + Foundation only. No AppKit, SwiftUI, or Cocoa.

Per hexpal-project.mdc, this directory holds pure functions and types with zero side effects — independently testable, no UI dependencies. Every file here must have a corresponding `*Tests.swift` in HexPalTests/.

**v2:** Color math (OKLCH, WCAG, APCA, ΔE) will be implemented here as pure Swift.
